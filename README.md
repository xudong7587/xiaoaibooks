# 小爱听书 · XiaoAiBooks

**本地自托管的听书项目，仅用于技术探索。作者不提供、托管或分发任何媒体源、书源订阅、音视频版权文件或付费资源。**

在自己的 NAS 上部署，管理自己有权使用的资源，将听书或 Navidrome 音乐投送至家中的小爱音箱，也可以在浏览器收听。“本地”指服务由自己部署；用户导入的在线书源按需解析和流式转发，不在 NAS 下载或保存有声书文件。

本仓库提供部署文件和版本记录，镜像通过 GitHub Container Registry 分发，不包含开发工作区或任何用户的账号、书源和配置。

## 功能

- Sunny UI 管理台：设备与连接、书源管理、节目准备、本地音乐、用户管理、播放与交互、其他设置。
- 用户自行导入书源，搜索并选定版本、章节和主播，为节目设置共享的唯一关键字与封面。
- 普通用户凭管理员注册码注册；节目共享，每个账号独立保存收听进度。
- 小米账号连接、音箱发现与绑定、播放、暂停、续播和持久断点。
- 已准备的听书节目可自动生成“小爱训练”的完整口令，固定回复“好”；支持明确序数的“第2季／第二季”读法。
- Navidrome 专辑、歌曲、歌手、封面与歌词；可在网页或已授权音箱收听。
- 企业微信独立自建应用：管理员搜索与编号选择节目，接收播放、暂停和自然结束通知，转发简单算术验证任务。

## Docker Compose 部署

支持 Linux `amd64` 和 `arm64`。复制下面的 Compose，只需要设置 **NAS 端口、数据目录和至少 8 位的管理员令牌**；不需要 `.env`，也不在这里填写小米等账号。

```yaml
services:
  app:
    image: ghcr.io/xudong7587/xiaoaibooks:0.2.13
    container_name: xiaoaibooks
    ports:
      - "18765:18765" # 左侧为 NAS 端口
    volumes:
      - "./data:/data" # 左侧为你的数据目录
    environment:
      P0_ADMIN_TOKEN: "" # 必填：设置至少 8 位的管理员令牌
    restart: unless-stopped
    stop_grace_period: 90s
```

保存为 `compose.yaml`，填写 `P0_ADMIN_TOKEN` 后，在该文件目录执行：

```sh
docker compose up -d
```

打开 `http://NAS局域网IP:18765/admin`，用你填写的管理员令牌登录。普通用户入口为 `/play`。小米、Navidrome 和企业微信的账号都在网页中配置。管理员登录密码也可在“其他设置”修改，最低 8 位。

左侧 `18765` 可改为你要的端口；左侧 `./data` 可改为 NAS 的专用绝对目录，例如 `/volume1/docker/xiaoaibooks/data`。右侧的 `/data` 与端口 `18765` 保持不变。该目录保存私有设置、书源和断点，升级容器时继续使用同一个目录。

令牌为空或不足 8 位时，容器会提示并拒绝启动。容器首次启动自动准备新数据目录，服务随后以普通用户运行，无需填写 UID/GID 或额外执行权限脚本。

## Docker 命令部署

同样只需修改端口、专用数据目录与至少 8 位的管理员令牌：

```sh
docker run -d \
  --name xiaoaibooks \
  --restart unless-stopped \
  --stop-timeout 90 \
  -p 18765:18765 \
  -v /你的数据目录:/data \
  -e P0_ADMIN_TOKEN='替换为至少8位的管理员令牌' \
  ghcr.io/xudong7587/xiaoaibooks:0.2.13
```

## 首次设置

1. **设备与连接**：登录自己的小米账号，完成小米要求的官方身份验证，发现并设置音箱房间、内网地址和默认进度账号。
2. **书源管理**：首次安装没有书源。自行导入有权使用的插件包，选择启用项。项目不提供书源下载地址。
3. **节目准备**：搜索、选择具体版本与章节，设置不重复的关键字，例如“睡前三国”。
4. **播放与交互**：先通过网页确认资源可播放，再开启对应房间的语音监听。管理员可设置多个启动词，用逗号分隔。
5. **节目训练自动同步**：连接已保存的小米账号的独立训练会话，再启用同步。准备好的听书节目会组合启动词和关键字创建私有训练；页面显示实际同步结果。不会自动发布训练，也不覆盖无关的人工训练。
6. **用户管理**：创建注册码，普通用户在 `/play` 注册；各账号从自己的断点续听。

### 小米登录与二次验证

登录需要“手机号或小米账号＋小米账号密码”，不支持只填账号后用短信验证码登录。

如小米要求二次验证，在“设备与连接 → 小米账号”点击“打开小米官方验证页面”，按钮会在浏览器新标签页打开官方链接，不会自动弹窗。在官方页面按要求完成短信等验证，再回到管理页点击“重新连接”，无需重填账号密码。电脑或手机浏览器均可操作；手机用于接收短信。

刷新管理页或重启服务后，仍可打开待处理的官方验证链接并继续连接。官方链接过期时，点击“重新连接”获取新的验证要求。可取消待连接账号；新账号连接成功前保留原账号。此版本已验证本地模拟验证流程，真实小米风控与短信送达仍需用户在实际环境完成确认。

先说“小爱同学”唤醒，再说“本地听书 睡前三国”。有进度时继续收听；暂停与继续可以直接说“暂停”“继续”，无需添加“本地”。音箱语音采用该设备设置的默认账号。

## 从网址导入与检查书源更新

“书源管理 → 导入书源 → 从网址导入”支持用户提供的 ZIP 直链或 GitHub 仓库／发布页。发布页按最新正式 Release 查找唯一的书源 ZIP，不会下载安装 APK。先检查版本、文件名、大小和 SHA256，再点击导入；内容变化时需重新检查。

成功导入后会记住更新地址，下次点击“检查书源更新”即可重新获取。GitHub 发布页会跟随最新版本；固定 ZIP 直链只检查同一文件是否变化。刷新不会自动替换现有书源。无法获得发布方摘要时会明确提示，不能把自行计算的 SHA256 说成发布方验证。新书源要能被当前运行器注册；失败时保留原书源包、节目、进度和启停选择。

下载由服务端完成，仅接受公网 HTTP/HTTPS，检查 DNS 和跳转地址，限制文件大小与超时。镜像不预填任何书源网址，也不包含书源包。

书源导入遇到格式错误、名称与内置入口冲突或保存失败时，会明确报错并保留原配置。搜索结果与目录会检查必要的名称和资源编号；坏目录不能保存为节目。请求期间更换书源包后，需要重新搜索和确认版本。点播关键字全家共享，重复时会保留当前表单供修改；重复添加同一版本会沿用已存在的节目与关键字。

## 书源验证码

在“书源管理”的对应列表行点击“展开验证”，可随时收起，待办会保留；通过后点击“关闭验证”移除该任务。取消待验证任务会结束该题。桌面和平板的一级侧栏固定在左侧，手机使用菜单抽屉。算术题填写数值答案后重试搜索；滑块题由用户在实时画面中亲自点击或拖动，松手后更新画面，再点击“重试原搜索”。企业微信验证码按听书账号逐题发送：当前题确认通过、取消或过期后，再发送下一题；答错或未回复时继续等待，旧题的排队回复不会误提交到下一题。尚未发出的题不能通过任务编号抢答。

支持动态加载、内嵌题目，以及常见 `vdimgck.php` 图片格式；页面中的普通搜索框不会被当成答案框。

画面会自动更新。“刷新画面”重新获取当前截图；“重新加载网页”保留当前账号、书源的会话并重载页面。手机可切换“原尺寸查看”后滚动操作。等待中的网页也会显示，避免题目未加载时直接被丢弃。登录、会员或短信限制请更换书源；第三方验证服务可能因站点策略或网络而无法工作，需要用户自行测试。滑块不参与 AI 算术题辅助，企业微信回复仍仅接收数值答案。

## 玻璃外观与网页设备切换

在“外观”的材质卡片选择“iOS 玻璃”，下方“玻璃透明度”滑杆调节表面透明程度，偏好保存在当前浏览器。折射与方向边缘高光参考 SunnyTV 的透镜方案，文字控件保持独立；浏览器不支持折射时使用低扩散回退，高对比度或减少透明度模式使用实色。网页效果不等同于 Android 原生渲染。

网页播放器可操作暂停、继续、上一首／下一首及停止。切换发声设备即明确发起接管：暂停原播放、保存可确认的断点，转移队列和模式后自动播放目标设备；仅能选择有权限的设备。若无法确认原设备已暂停，切换会报错，避免两端同时发声。手机浏览器的自动播放限制仍可能要求再点一次播放。

## 本地音乐与限制

在“本地音乐”连接自己的 Navidrome，填写地址、用户名和密码，点击“保存并连接”；验证成功才保存，失败保留原配置和播放会话。音乐不经书源系统获取；无损音乐可请求 Navidrome 转为 MP3，需 Navidrome 已配置 FFmpeg 和转码规则。

推荐使用“我的”系列口令，可在“播放与交互 → 语音交互”自定义；推荐项仅为通用文本，不携带任何人的训练记录或账号。先说“小爱同学”唤醒，例如：

- “我的音乐 湖泊”：单曲点播，并建立该歌手的全部歌曲队列，按歌名排序接续并列表循环。
- “播放歌单 音乐缘计划”：播放 Navidrome 已有歌单，默认列表循环。
- “播放周杰伦的歌”：按年份从早到晚，同年按专辑音轨组织播放。
- “我的音乐专辑 范特西”：播放指定专辑。
- 播放中可说“随机播放”“单曲循环”等切换模式。实际识别效果依型号、固件及小爱服务而异，需自行测试口令。

音乐使用“我的歌曲＋歌名”等通用启动口令直接搜索 Navidrome，允许小爱的原生提示。播放新歌不会自动加入“节目准备”，不会创建逐首点播关键字或自动同步歌曲训练。内部仅保存续播、播放队列和统计所需的歌曲引用；同一首歌重复播放复用该引用。升级会把先前自动产生的 Navidrome 音乐条目转为内部记录，释放旧关键字并保留队列、账号断点和历史；听书节目规则继续保留。

网页底部使用统一播放器，可在网页与有权限的音箱间切换、查看和编辑播放列表、暂停／停止、选择播放模式及调整音量。选择音箱时，音量控制读取并设置音箱真实音量。点上箭头展开一体卡片：左侧封面、中间歌词、右侧列表；下箭头收起。手机窄屏使用左上角导航抽屉，歌词和列表切换显示，已用 320、390 像素视口验证布局，可用于手机浏览器或 WebView。尚未实机验证所有 WebView、添加到主屏后的后台播放及锁屏控制。

口令推荐不能保证所有设备均能避免原生“不支持本地音乐”提示。节目训练不会为整个音乐库逐首建训练。
当前小米语音交互通过云端识别记录轮询，并非固件内拦截。没有对所有型号、固件或网络条件作兼容保证。L15A 与 X08E 有实机验证；X08E 使用触屏兼容投放，音箱屏幕可能显示厂商占位曲目，网页和通知显示实际资源。

音箱位置与媒体取流核对通过后才保存有效播放状态。网络中断、资源过期和固件差异可能影响定位；暂停后再升级可减少断点损失。容器重启不会自行开播。

## 企业微信（管理员专用）

使用独立自建应用，并在企业微信后台把应用可见范围限制为管理员。在“其他设置 → 企业微信交互”保存企业 ID、AgentId、Secret、Token、EncodingAESKey，启用接收消息，设置 HTTPS 回调 `/api/wecom/callback`。

启用管理员专用模式后，无需绑定普通用户或输入绑定码。配置明确的管理员 UserId 名单时，只处理名单成员；使用从应用识别管理员的模式时，先由管理员向应用发送一条消息，项目记录该签名有效的应用成员。真实出站通知不使用 `@all` 广播。

向应用发送“三体”或“准备 三体”，收到编号候选后，在有效期内回复“编号 关键字”，例如“2 睡前三体”。准备资源不会播放。搜索与回复状态显示在管理页；出网 IP 等企业微信平台限制仍需按官方要求配置。

播放、继续、暂停及自然结束通知由管理员按需启用，只发送给管理员名单。自然结束需要实际观测到终点，失联或重启不会冒充结束。

## 外网、更新与备份

需要外网网页或企微回调时，自行配置 HTTPS 反向代理，保留原始 Host，并在管理台填写公网服务地址。公网管理默认关闭，可按需要启用；仍需管理员登录。异地音箱入口暂时隐藏。

镜像使用固定版本标签。更新到新版本时，先将 `compose.yaml` 中 `image:` 的版本改为目标已发布版本，核对该版本清单，再执行：

```sh
docker compose pull
docker compose up -d
```

新版 Compose 示例用于新部署。升级时保留原来的 `/data` 卷或目录映射及已有 `user` 设置，不要换成新的空目录。若沿用 0.2.0 公开模板中的 `cap_drop: [ALL]`，且原来没有写 `user`，请补上 `user: "10001:10001"`，继续使用旧版数据属主；不要只换镜像版本。这条兼容设置仅用于旧模板，新部署使用上面的精简示例即可。

更新前备份映射的数据目录；数据库使用 SQLite，建议停容器后备份该目录，或使用 SQLite 在线备份。不要把账号、会话、Cookie、私有书源或备份提交到 GitHub。`docker compose down` 不会删除映射的数据目录；请勿手动清空该目录。
